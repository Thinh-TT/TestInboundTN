GitHub Issue ➔ Task Kanban

Mở Issue mới trên GitHub Repo. TeamNexus tự động tạo thẻ task mới trong bảng Kanban được chỉ định bằng tài khoản GitHub Bot và kích hoạt Jev AI Triage.

Title: [Bug] Lỗi giao diện trang chủ mobile
Kịch bản 2

Tên nhánh & Commit liên kết

Tạo nhánh hoặc viết commit chứa mã thẻ (ví dụ TN-1). TeamNexus sẽ nhận diện và hiển thị link liên kết tới commit đó.

git checkout -b feat/TN-1-landing-ui
git commit -m "feat(ui): [TN-1] add hero banner"
Kịch bản 3

Tạo PR ➔ Chuyển "In Review"

Tạo Pull Request với tiêu đề hoặc nội dung chứa mã task (ví dụ TN-1). Thẻ task trên bảng Kanban tự động chuyển sang cột In Review.

PR Title: feat: TN-1 redesign web header
Kịch bản 4

Merge PR ➔ Tự Động "Done"

Khi PR được merge vào nhánh chính (main), Task tương ứng tự động chuyển sang cột Done và ghi vết AiActionLog có thể hoàn tác.

Merge pull request #1 from feat/TN-1-landing-ui
Kịch bản 5

Đồng bộ Bình luận hai chiều

Thêm comment thảo luận trên GitHub Issue hoặc PR. TeamNexus sẽ tự động tạo comment tương ứng trong thẻ task với nhãn via GitHub @username.

Comment: "Đã sửa xong phần CSS responsive, chờ review."
